How relations work

When money is added (credited) to a source category, each active rule quietly routes a share to a target. Choose percent or a fixed amount. Deduct on moves money (the source keeps the remainder). Deduct off mirrors it (the source keeps everything, the target receives a copy). A category with no active rules is independent.
